# UmaScope Free AutoBet 1.15 — 省容量モード

## 直近8走だけ詳細保存
各馬の近走は直近8走を詳細保存します。

9走目以降は完全削除せず、
- 全体パフォーマンス
- 芝 / ダート
- 競馬場
- 距離帯
- 馬場状態
の集計値へ圧縮します。

この集計値は1着・2着内・3着内モデルへ弱く反映するため、古い情報を完全には捨てません。

## AI学習データも圧縮
従来の verbose な aiForecast を数値配列 aiForecastPacked に変更しました。

保持するもの:
- 1着確率
- 2着内確率
- 3着内確率
- 役割別順位
- 能力 / 適性 / 展開 / 騎手 / 調子

そのため確率校正とウォークフォワード学習は継続できます。

## 買い目も短縮保存
AI提示買い目と購入候補買い目を短縮形式で保存します。
的中判定・公式払戻・回収率計算は従来どおり可能です。

## 一時データ
- 取込本文は解析成功後に画面から削除
- 現在レースは軽量形式のみ保存
- AI予想を保存した後、現在レースの一時保存を自動削除

## 既存データの整理
「使い方 → 不要データを整理」を押すと、
過去の20走馬DB・冗長なAI履歴・重複バックテストデータを圧縮します。

残るもの:
- AI予想
- AI順位
- AI買い目
- 実結果
- 公式払戻
- 的中率
- 回収率
- 学習に必要な指数と確率

## ストレージ表示
使い方画面で
- UmaScope LocalStorage使用量
- 馬DB頭数
- 近走詳細件数
- 古い近走集計件数
- Safari対応時はサイト保存領域の使用量 / 上限
を確認できます。
