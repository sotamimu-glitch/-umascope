# UmaScope Free AutoBet 1.5 — JRA近走取込修正版

## 1.5の主な修正
- JRAは「スマートフォン用 詳細出馬表」を開かなくても、通常の出馬表で取込可能に変更
- JRA取込ブックマークを軽量化（巨大なHTMLをコピーしない）
- JRAの前走〜4走を、テーブル単位・本文ブロックの両方から解析
- `14頭14番11番人気` のように空白が少ないJRA表記にも対応
- 芝/ダート、距離、馬場、騎手、着差を近走から抽出
- 取込結果に「今回取得した近走 ○件」を表示
- 1.4までの履歴・馬DB・バックテスト・券種別的中率を継承

## JRAの使い方
1. JRA公式サイトで対象レースの通常の「出馬表」を開く
2. Safariブックマークの「UmaScope取込」を実行
3. UmaScope 1.5 →「クリップボードから解析」
4. 「今回取得した近走」が0件ではないことを確認

スマートフォン用詳細出馬表は開かなくてかまいません。
PC表示（Safariのデスクトップ用Webサイト）でも同じ取込コードを使えます。
