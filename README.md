# UmaScope Free AutoBet 1.8 — 総合判定＋大きな見送り表示

## 追加した機能

### 各馬の総合判定
10特徴量の加重平均を100点満点に換算し、S〜Dでも表示します。

- S：80〜100点
- A：70〜79点
- B：60〜69点
- C：50〜59点
- D：49点以下

総合点は次の10特徴量から算出します。
1. 着差 16%
2. 人気 8%
3. 頭数 8%
4. 距離変化 12%
5. 芝・ダート 10%
6. 馬場状態 8%
7. 騎手 10%
8. 枠順 5%
9. 斤量 7%
10. 近3〜4走の推移 16%

各馬カードと予想ランキングの両方に「S〜D / 100点」を表示します。

### 見送り表示
現実的買い目が0点の場合、予想結果の一番上に大きく

**見送り**

と表示します。

見送りになる主なケース:
- EV基準を満たさない
- 的中確率が低すぎる
- モデル信頼度が低い
- 実オッズが不足して購入判断できない

買い目がある場合は「購入候補あり」と表示します。
