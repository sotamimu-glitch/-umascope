# UmaScope Free AutoBet 1.19.1 — 1.19効果検証

## 予測ロジック
1.19から変更していません。
買い目生成・購入フィルター・同日馬場バイアス・レースLV補正・確率校正も同じです。

## 追加した分析
分析 → 「1.19 効果検証」

### すぐ確認できるもの
既存の1.19履歴を使って:
- 馬場バイアスON vs OFF
- 前有利 / 差し有利 / 内有利 / 外有利等
- 中央 vs 地方

について
- レース数
- AI1位→1着率
- 上位3頭に勝馬
- 単勝の公式ROI
- 複勝の公式ROI
を比較できます。

### 1.19.1以降に詳細蓄積するもの
予想保存時に追加診断情報を軽量保存します。

- レース全体の平均レースLV
- AI1位馬のレースLV
- AI1位馬と全体平均のLV差
- 文脈別確率校正を使ったか
- 校正対象条件

これにより今後、
- AI1位が高レースLVだった時
- LV差が小さい時
- AI1位が低レースLVだった時
- 文脈校正あり
- 全体寄り校正
の成績を比較できます。

## 注意
馬場バイアスON/OFFはランダム化実験ではありません。
ONは同日の後半レースに偏るため、成績差をそのまま「バイアスの因果効果」とは判断しません。
弱い機能を見つけるための診断として使います。
