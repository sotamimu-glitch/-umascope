# UmaScope 1.22.5 — JRA馬連/ワイド直接取込修正

- JRAの馬連・ワイドは同じ accessO.html でも、ページ内部の表示内容が異なります。
- `table.umaren` / `table.wide` を直接解析します。
- `caption` を1頭目、各行の先頭を2頭目として全組み合わせを復元します。
- ワイドは表示レンジの下限をC判定に使用します。
- ページ側の表から馬連/ワイドを自動判別します。
- 馬連ページとワイドページを別々に取り込み、既存オッズへマージします。
- 仮候補=黄、見送り=赤、購入候補=緑。

## iPhone手順
1. GitHubを更新
2. UmaScopeをSafariで再読み込み
3. 設定から新しい「オッズ取込コード」をコピーして、Safariのオッズ取込ブックマークURLを置き換える
4. JRAの馬連「馬番順」ページでブックマーク実行
5. UmaScopeで「このページのオッズを追加」
6. JRAのワイド「馬番順」ページでも同じ操作
7. 馬連/ワイド件数を確認してCを保存・更新

16頭なら各券種の全組み合わせは最大120組です。
