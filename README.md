# UmaScope Free AutoBet 1.19 — 予測精度強化

1.18の条件別ROIランキング、単複中心の購入ロジックは維持しています。
今回はオッズ前の予測確率そのものを改善する更新です。

## 1. 同日馬場バイアス
同じ日・同じ競馬場・同じ芝/ダートで、前のレース結果が2R以上入力済みの場合に利用します。

前半レースの1～3着馬について、
- 逃げ / 先行 / 差し / 追込
- 内枠 / 外枠
を集計し、
- 前有利
- 差し有利
- 内有利
- 外有利
- 中立
を判定します。

バイアスは役割別スコアへ最大でも小さな補正として入れます。
前半結果が不足している時は自動的に使いません。

重要:
前半レースをUmaScopeで予想保存し、結果を入力してから後半レースを予想した場合に効きます。
過去1.18以前の履歴には脚質・枠の軽量データがないため、1.19以降から蓄積します。

## 2. 過去レースレベル補正
過去走ごとに
- クラス
- 頭数
から「レースレベル」を推定します。

同じ5着でも、
上位クラス・多頭数のレースで走った5着を少し高く評価し、
弱い条件での5着とは区別します。

レースレベルは能力指数と直近内容に中程度以下の重みで反映します。

## 3. 文脈別確率校正
従来の中央/地方別校正に加えて、
十分なサンプルがある場合は
- 芝 / ダート
- 距離帯
を優先して確率を校正します。

サンプル不足では自動的に
芝ダ単位 → 競馬場単位 → 全体
へ戻します。

少数データで過剰補正しないようBayes型の縮小を入れています。

## 4. オッズと予測確率を分離
1着確率 / 2着内率 / 3着内率の計算にはオッズを使いません。
オッズを取得した後だけEVを計算します。

そのため、
「馬の予測精度」と「市場オッズとのズレ」を分けて検証できます。

## 5. 分析
分析画面に「1.19 精度改善ステータス」を追加。
- 1.19保存レース数
- 同日馬場バイアスが実際に反映されたレース数
- 1.19のAI順位精度
を確認できます。

条件別ROIランキングでは
- 1.17以降
- 1.19以降
- 全期間
を切り替えられます。
