# UmaScope Free AutoBet 1.21 — 結果・払戻かんたん取込

## 1.21の追加機能

### 1. 公式結果ページから一括取込
新しいSafariブックマークレット **「UmaScope結果取込」** を追加。

JRA/NARの公式結果ページで実行すると、
- 1着
- 2着
- 3着
- 単勝/複勝
- 馬連
- ワイド
- 三連複（旧履歴用）

の結果・払戻をコピーします。

UmaScopeの「成績」→「クリップボードから結果取込」で、
保存済みレースを照合して一括反映します。

### 2. 手入力も簡略化
手入力の場合は1〜3着を入れて
**「着順から必要払戻を表示」** を押します。

すると、AI提示買い目のうち「的中した買い目」だけ払戻入力欄が出ます。

例:
- 馬連 3-8 的中 → 馬連3-8の払戻だけ入力
- ワイド 3-6 外れ → 入力欄なし
- 全買い目外れ → 払戻入力そのものが不要

### 3. 特殊ケース
同着・返還などは「特殊ケース」を開けば従来どおり追加入力できます。
