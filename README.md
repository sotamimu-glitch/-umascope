# UmaScope Free AutoBet 1.20 — 軸→穴・回収率優先

予測モデルは1.19系を維持し、購入戦略を変更しました。

- 的中率より回収率を優先
- 購入候補は馬連またはワイドのみ
- 1レースで両方は買わず、回収期待が高い方を選択
- 軸馬を1頭選び、吟味した穴馬へ流す
- 最大3点・各100円
- 馬連 10.0倍以上
- ワイド 5.0倍以上
- 推定EV 1.05以上
- 条件未達は見送り
- ワイドは取得したオッズ範囲の下限値で判定

穴馬指数は、2着内/3着内確率、役割別順位、適性、展開、調子、単勝オッズがある場合の穴度を組み合わせます。

分析画面に「1.20 軸→穴 回収率戦略」を追加し、1.20だけの購入候補レース的中率・公式払戻ROI・馬連ROI・ワイドROI・軸馬3着内率を別集計します。
