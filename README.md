# UmaScope Free AutoBet 1.19.3 — 強候補シャドーテスト

予測ロジック・購入判定は1.19.2から変更していません。

## 目的
1.17以降の条件別ROIで高かった条件を、そのまま購入ルールへ入れず、
1.19.3以降の将来データだけで前向きに検証します。

既存履歴への後付けバックテストはしません。
そのため、現在見つかった条件への過学習をできるだけ避けます。

## 固定シャドールール

### 単勝
- 予測勝率 10～14%
- 2100～2400m
- 12倍以上 × 荒
- 芝 × 荒
- 中央 × 荒

### 複勝
- 2100～2400m
- 2100～2400m × 堅
- 芝 × 堅

1つ以上一致 = A
2条件以上一致 = A+

## 表示
予想画面:
- 検証用の強候補シャドーを表示
- 実購入候補判定には影響しない

分析画面:
- 強候補該当レース数
- レース的中率
- 公式払戻ROI
- A+ ROI
- 単勝ROI
- 複勝ROI
- 各固定ルール別の点数 / 的中率 / ROI

## 回収率
結果入力時の公式100円払戻を使用します。
的中したシャドー買い目の公式払戻が未入力のレースは、ROI確定分から除外します。
