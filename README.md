# UmaScope Free AutoBet 1.20.1 — 予想オッズ対応

## 変更点
1.20の「軸1頭→穴馬、馬連orワイド、回収率優先」を維持し、
**オッズ発表前でも予想オッズで事前判定**できるようにしました。

### 予想オッズの作り方
実オッズとは別の「市場予測モデル」を使います。

- 過去の人気順位
- 近走着順
- 騎手指数
- 能力指数
- 調子指数
- 単勝オッズが一部だけ出ている場合はその市場情報

から、各馬が市場でどの程度買われそうかを推定し、
馬連・ワイドの予想オッズを作ります。

**AI本体の1着確率・3着内確率をそのまま逆算して予想オッズにはしていません。**
これにより、AI確率と予想オッズを同じ数字から作ってEVを水増しするのを避けます。

### 保守判定
画面には予想オッズの中間値を表示しますが、
買い目判定には予想オッズの下振れを考慮した「保守オッズ」を使います。

- 馬連: 保守オッズ 10.0倍以上
- ワイド: 保守オッズ 5.0倍以上
- EV: 1.05以上

### 実オッズ取得後
同じ組み合わせに実オッズが入ったら、
**予想オッズではなく実オッズを自動で最優先**します。

- オッズ前 → 「仮購入候補あり」または「事前見送り」
- 実オッズ後 → 「購入候補あり」または「見送り」

### 検証
分析画面に以下を追加:
- 予想オッズ候補レース数
- 実オッズ候補レース数
- 予想オッズと実オッズの比較データがある場合の平均誤差

今後データが蓄積すれば、予想オッズモデル自体の補正に使えます。
