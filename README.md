# UmaScope Free AutoBet 1.22 — 回収率優先3段階分析

## 1.22の考え方

的中率の下限は置かず、長期の回収率を優先して購入レースを絞ります。
購入候補は **馬連 / ワイドのみ**。

- 馬連: 10倍以上
- ワイド: 5倍以上
- 最終購入条件: 実オッズで推定EV 1.50以上
- 1レース最大2点

## A → B → C の3段階

### A: 開催前の事前分析
同日馬場補正を使わず、全レースを同じ条件で予測します。
オッズ未発表なら予想オッズの保守側で仮候補を作ります。
Aの候補はシャドー保存で、実購入候補には数えません。

### B: 同日3R後の再分析
同じ日・同じ競馬場・同じ芝/ダートで、前レースの結果が3R以上保存されている場合だけ馬場傾向を弱く反映します。
Bもシャドー保存です。

### C: 実オッズ最終判定
実際の馬連/ワイドオッズがある買い目だけを評価します。
予想オッズは使わず、実オッズでEV1.50以上かつ最低オッズを満たしたものだけ「購入候補あり」にします。

## 券種別の軸
- 馬連: 2着内確率を重視して軸を選択
- ワイド: 3着内確率を重視して軸を選択

同じAI総合1位を自動的に両券種の軸にはしません。
