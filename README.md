# UmaScope Free AutoBet 1.9

## 6指数へ集約
- 能力指数：着差・着順/頭数・人気
- 適性指数：距離・芝/ダート・馬場状態・競馬場成績・枠順
- 展開指数：近走のコーナー位置取りとレース内の先行馬比率から簡易推定
- 騎手指数：今回騎手との近走パフォーマンス
- 調子指数：近3〜4走の上昇/下降、直近内容、斤量変化
- 妙味指数：推定勝率と実オッズの乖離（EV1.00=約50、EV1.20=約70）

総合点/S〜Dは妙味を除く5指数から作り、能力順位がオッズに引っ張られないようにしています。

## 地方競馬の近走修正
2026年9月時点のNAR詳細出馬表の「競馬場+月日 馬場 右/左 距離」「着順/頭数 人気 騎手 斤量」「着差 コーナー位置」の形式に対応。Safariで本文がセル単位に分かれても、各セルと行テキストの両方から近走を復元します。

## 120% / 70% 目標モード
購入候補にするのは、原則として各買い目の推定EVが1.20以上のもの。そこから最大5点まで選び、モデル上「どれか1点が当たるレース的中確率」が70%以上になった場合のみ購入候補にします。両方を満たさなければ見送りです。

これは将来の実回収率120%・実的中率70%を保証するものではありません。分析画面で保存予想の実績を継続検証してください。
