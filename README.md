# UmaScope Free AutoBet 1.14 — 公式払戻・確定回収率版

## 回収率の計算を変更
メインの回収率を「保存時オッズ × 的中」から、
レース確定後の公式100円払戻金ベースへ変更しました。

回収率 = 公式払戻総額 ÷ 100円均等投資総額 × 100

## 結果入力
各履歴で
- 1着 / 2着 / 3着
- 単勝100円払戻
- 馬複100円払戻
- ワイド3通りの100円払戻
- 三連複100円払戻
を入力できます。

## 同着・返還
通常欄に入らない追加払戻は
`単勝:5=680, ワイド:5-7=720`
の形式で追加できます。

返還は
`単勝:4, 馬複:4-7`
の形式で入力すると100円返還として計算します。

## 3種類を分離
### AIが出した全買い目
購入候補・見送りを問わず、全AI提示買い目を100円均等買い。

### 購入候補だけ
AIが「購入候補あり」とした買い目だけを100円均等買い。

### 実際の購入
自分で入力した実投資額・実払戻額から実収支回収率を計算。

## 未入力の扱い
ハズレ買い目は着順だけで払戻0円が確定します。
的中買い目の公式払戻が未入力の場合、そのレースは確定回収率の母数へ入れません。
画面に「公式払戻まで確定 X/Yレース」と表示します。

## 理論回収率
予想時オッズを使う従来の回収率は削除せず、
分析画面の「予想時オッズ理論バックテスト」に参考値として残します。
