# UmaScope Free AutoBet 1.8.1 — 表示不具合修正版

## 修正内容
1.8で「見送り / 購入候補あり」を表示する部分に、ネイティブDOMでは使えない
jQuery形式の `.attr().show().html()` が混ざっていました。

iPhone Safariでは予想処理がそこで停止し、
- 「見送り」
- 「購入候補あり」
- 「この予想を保存」
が表示されない状態になっていました。

1.8.1ではネイティブDOM APIに修正しています。

## 予想後の表示
予想を実行すると結果欄の一番上に必ず次のどちらかが表示されます。

- 見送り
- 購入候補あり

その下にランキング・買い目が表示され、最後に
「この予想を保存」ボタンが表示されます。

見送りの場合でも予想を保存できます。
履歴には「買い目0点 / 見送り判定」として保存されます。
