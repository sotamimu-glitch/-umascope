# UmaScope Free AutoBet 1.22.1 — C再分析修正版

## 修正した問題
1.22ではC判定に馬連・ワイドの実オッズが必要でしたが、
JRAの出馬表取込では組み合わせオッズが入らず、Cへ切り替わらない場合がありました。

さらに、C再分析後は「この予想を保存」をもう一度押さないと履歴が更新されないため、
再分析結果が反映されていないように見える問題がありました。

## 1.22.1
- JRAの「オッズ」リンクから馬連・ワイドページを探索して自動取得
- 自動取得できない時の「C：実オッズ手入力・貼付」を追加
- Cになったら「C最終判定を保存・更新」と明示
- 現在の実オッズ取得件数（馬連/ワイド）を表示
- A/B保存後も現在レースを端末に保持し、C更新しやすく変更
- C更新時にA/Bシャドーを再計算して上書きしないよう修正
  - AはAを保存した時点
  - BはBを保存した時点
  - CはCを保存した時点
  のスナップショットを保持

## Cの使い方
### 自動
1. Cの時間（5〜10分前）にJRA/NARの出馬表を開く
2. 更新した「UmaScope取込」を実行
3. UmaScopeでクリップボード解析
4. 「現在の分析段階：C」を確認
5. 「C最終判定を保存・更新」

### 自動で入らない場合
「C：実オッズを手入力・貼付して再分析」を開いて、

馬連 3-8=14.6
馬連 3-11=22.4
ワイド 3-8=5.8
ワイド 3-11=8.1

のように候補組の実オッズだけ入力し、
「実オッズを反映 → C再分析」を押します。
