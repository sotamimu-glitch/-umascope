## 少数サンプル対策
10点以上の条件だけをランキング対象にします。
順位は、実ROIそのものではなく
「20点分・ROI100%」を事前値として混ぜた補正ROIで並べます。

そのため、たまたま2～3回高配当が当たっただけの条件がトップになりにくくしています。

## ★200%候補
以下をすべて満たした条件だけ表示:
- 25点以上
- 公式払戻ROI 200%以上
- 少数補正後ROI 150%以上

これは将来のROI200%を保証するものではなく、次の購入フィルター候補を探すための診断です。
