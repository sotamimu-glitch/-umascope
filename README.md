# UmaScope Free AutoBet 1.11 — 券種別検証統一 / 組み合わせ券種修正版

## 今回の方針
45レース時点で単勝の100円均等回収率が良く、ワイド・馬複・三連複が弱かったため、
単勝の推薦ロジックは維持し、組み合わせ券種だけを重点的に変更しました。

## 1. 券種別成績を完全に同じ母集団へ統一
1.10.1までは
- 「的中率」＝購入候補
- 「100円BT」＝AI提示バックテスト候補
という別データを見ていたため、「的中0/0なのにBT90点」のような表示がありました。

1.11では券種別の
- 提示点数
- 的中数
- 的中率
- 100円均等買い回収率
をすべて `AIが実際に提示した買い目` から計算します。

## 2. ワイド・馬複・三連複を再設計
従来はEV上位を強く優先していたため、高配当だが当たりにくい組み合わせが上に来ることがありました。

1.11では:
- ワイド: AI上位1〜4頭のうち、1-2 / 1-3 / 2-3 / 1-4を中心に最大2点
- 馬複: 1-2 / 1-3 / 2-3を中心に最大2点
- 三連複: 1-2-3を最優先、次に1-2-4 / 1-3-4から最大1点
- 選択順位は的中確率を主、EVを副に変更

単勝は1.10.1の選び方をそのまま維持しています。

## 3. ワイド的中判定を再検証
ワイドは1〜3着のうち選んだ2頭が両方入れば的中です。
馬番順が逆でも的中します。
馬複と三連複も馬番順に依存しません。

この判定を回帰テストに追加しています。

## 4. 新ロジックだけの成績も表示
過去45レースの履歴は書き換えません。
そのため券種別カードに
`1.11以降: 的中率 / 回収率`
を別表示し、新しい組み合わせロジックの改善度を比較できます。
