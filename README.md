# UmaScope Free AutoBet 1.12 — 精度改善フルアップデート

## 1. 着順別確率を分離
各馬について
- 1着確率
- 2着以内確率
- 3着以内確率
を別々に表示します。

## 2. 6000回レースシミュレーション
推定強度を使って着順を6000回生成し、
- ワイド：2頭とも3着以内
- 馬複：2頭が1・2着
- 三連複：3頭が3着以内
を直接数えます。

単勝勝率だけから単純計算する方式をやめました。

## 3. 確率キャリブレーション
1.12形式で保存した予想と結果が蓄積すると、
予測30%が実際に何%当たったかを中央・地方別に学習して補正します。
少数サンプルでは補正せず、80サンプル以上から徐々に効かせます。

## 4. 6指数ウェイトを実績学習
能力 / 適性 / 展開 / 騎手 / 調子の5つ（妙味は除外）の重みを、
結果から中央・地方別に学習します。
30レース以上で70%学習・30%検証を行い、
後半データで悪化しない場合だけ最大50%まで学習値を混ぜます。

## 5. レース内相対評価
各指数の絶対点だけでなく、
そのレース内の平均との差・標準偏差を使って相対化します。
絶対評価56%＋レース内相対評価44%で予測強度を作ります。

## 6. 展開指数強化
近走コーナー位置から逃げ・先行・差し・追込を分類。
同じレースの逃げ/先行馬の数から先行圧力を計算し、
ハイペース/スローで有利な脚質を変えます。

## 7. 適性指数強化
- 同競馬場
- 同競馬場×近似距離（±200m）
- 芝/ダート
- 馬場状態
- 距離
- 枠
を統合。
少数実績は中立値へ縮小するため、1戦1勝だけで極端な高得点になりにくくしています。

## 8. クラス変化
JRAの新馬・未勝利・1勝・2勝・3勝・OP・G3/G2/G1、
地方のA/B/C級を可能な範囲で数値化。
前走からの昇級・降級を能力指数へ軽く反映します。

## 9. 休養間隔・馬体重履歴
調子指数に
- 前走からの日数
- 過去の馬体重変動
を追加。
現出馬表に当日馬体重がない場合は過去履歴の安定性だけを弱く使います。

## 10. オッズは能力から分離
妙味指数だけがオッズを使用し、
能力・適性・展開・騎手・調子の総合力にはオッズを入れません。

## 11. 券種別EV基準を学習
初期基準:
- 単勝 1.12
- ワイド 1.15
- 馬複 1.25
- 三連複 1.40

1.12の実績が25レース以上貯まると、
古い70%で候補基準を探索し、新しい30%で再現した場合だけ採用します。

## 12. AI順位そのものの診断
分析画面に
- AI1位→1着率
- 上位2頭に勝馬
- 上位3頭に勝馬
- 上位3頭から2頭以上が3着内
- 上位3頭が全て3着内
- AI1-2位で馬複一致
を表示します。

これにより「順位モデルが悪いのか」「買い目生成が悪いのか」を切り分けられます。
