# UmaScope Free AutoBet 1.10 — AI予想 ↔ 実結果 / 全提示買い目均等BT

## 追加した機能

### 1. AI予想と実際の結果を一目で比較
予想保存時に以下を保存します。
- AIランキング1〜3位
- 馬番と馬名
- 総合点・S〜D判定
- 「購入候補あり / 見送り」判定

レース結果で1着・2着・3着の馬番を入力すると、履歴に

AI予想 | 実際の結果

を横並び表示します。

さらに
- AI1位が1着だったか
- AI上位3頭のうち何頭が実際の3着内に入ったか

も表示します。

### 2. 購入候補・見送りを問わずAIが出した全買い目を検証
1.9では購入候補とバックテスト候補が分かれていました。
1.10では保存時に、画面へ出した参考買い目を `aiTickets` としてすべて保存します。

対象:
- 単勝
- ワイド
- 馬複
- 三連複

見送りレースの参考買い目も含みます。

### 3. 100円均等買い成績
各AI提示買い目を100円ずつ買ったと仮定して
- 採点済買い目数
- 買い目的中率
- レース的中率（そのレースで1点以上的中）
- 回収率

を表示します。

回収率は保存時オッズを使います。
オッズが保存されていない買い目は的中率には含められますが、
回収率には含めません。画面に「オッズ保存済み n点」で分母を表示します。
