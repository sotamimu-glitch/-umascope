# UmaScope Free AutoBet 1.17 — 単複メイン＋日別成績

## 購入方針
主力:
- 単勝
- 複勝

補助:
- 馬連
- ワイド

複勝は3着内モデルの確率を使用します。
同じ馬で単勝と複勝の両方が条件を満たせば、単複として両方が購入候補になることがあります。

複勝の初期EV基準は1.10。
馬連・ワイドは補助券種として購入基準を1.16より厳しくしています。

## 複勝オッズ
各馬に「複勝下限」入力欄を追加しました。
自動取得できた場合は入力済みになります。取得できない場合は公式ページの複勝オッズ下限を入力してください。
購入判定は保守的に下限オッズを使用します。

## 複勝の公式払戻
結果入力欄に、1着・2着・3着馬それぞれの複勝100円払戻を追加しました。
これにより複勝も公式払戻ベースで正確な回収率を計算できます。

## 日ごとの成績
分析 → 「日ごとの成績」

日付ごとに:
- 購入候補のレース的中率
- 購入候補の公式払戻・確定回収率
- AI全買い目の公式払戻回収率
を表示します。

## 既存データ
1.16以前の単勝・馬連・ワイド履歴はそのまま残ります。
複勝成績は1.17以降に蓄積されます。
