# UmaScope Free AutoBet 1.16.1 — 購入候補買い目表示

予測ロジック・購入判定・荒れ度予測は1.16から変更していません。

## 成績画面
- 「購入候補だけ」カードに「購入候補あり買い目を表示」を追加
- 開くと、購入候補になった全レースの買い目を一覧表示
- 券種 / 馬番 / EV / 推定確率 / 的中✓・不的中×を確認
- 各レースの履歴にも「購入候補あり買い目」を別枠表示
- 見送りレースは「購入候補なし」と表示

過去1.16の保存履歴もそのまま表示できます。データ形式・予測ロジックは変更していません。
