# UmaScope Free AutoBet

中央競馬（JRA）＋地方競馬（NAR）対応、月額0円・iPhone中心で使うPWAです。


## AutoBet追加機能
- 単勝に加えて馬連・ワイド・三連複の候補を自動生成
- 順位確率から各組合せの的中確率をPlackett–Luce型の逐次モデルで概算
- 実オッズが取得できた組合せは `推定EV = 概算確率 × オッズ` を表示
- オッズ未取得時は `EV 1.10` に必要な最低オッズを表示
- 地方競馬ではブックマーク実行時にNAR公式の単複・馬連複・ワイド・三連複オッズページを各1回取得
- EV 1.10未満しかない券種は「見送り」と表示

ワイドの公式オッズが範囲表示の場合は、期待値を過大評価しないよう**下限オッズ**を使用します。

## これまでの自動評価
- 出馬表取込後、取得できた過去走から5項目を自動評価
- スピード、近走、距離適性、馬場適性、騎手を1〜10でAUTO入力
- AUTO値は手動補正可能
- データ量に応じた信頼度表示
- 低信頼時は推定勝率を均等確率方向へ縮小
- 単勝オッズがあれば推定EVを自動計算
- 地方競馬ではブックマーク実行時に同一NAR公式内の詳細出馬表と単勝オッズを1回ずつ取得
- 中央競馬ではJRA出馬表の前走〜4走前を利用。オッズリンクを同一ページから取得できた場合は併せて取込

## iPhoneで使う
1. このフォルダをGitHub PagesなどHTTPSの無料静的ホスティングへ配置
2. iPhone Safariで開き「ホーム画面に追加」
3. アプリの「設定」にあるブックマークレットをSafariブックマークのURLに設定
4. JRA/NAR公式の対象レース出馬表を開き、そのブックマークを実行
5. UmaScopeで「クリップボードから解析」

## 自動スコア
- 近走: 着順を出走頭数で正規化し、直近を重視
- スピード: 近走評価＋取得できた着差
- 距離: 今回との距離差＋NARの距離別成績
- 馬場: 競馬場、馬場状態、コース情報と近走成績
- 騎手: 現騎手と同じ騎手での近走があれば反映。情報がなければ中立5

これは学習済みAIや利益保証モデルではありません。推定EVはモデル確率が正しいという保証がないため、参考指標として扱ってください。

## 無料運用方針
バックエンドによる常時スクレイピングやデータ再配布は行いません。ユーザーが公式ページ上でブックマークを実行した時だけ、必要最小限の情報を端末へ取り込みます。

## 買い目確率について
馬連・ワイド・三連複の確率は、UmaScopeが推定した各馬の相対確率から着順を逐次抽選する近似モデルです。実際の競走で必要な相関、脚質、展開、同着等を完全には表現しません。推定EVは利益保証ではなく、買い目を絞るための参考指標です。
