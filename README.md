# UmaScope Free AutoBet 1.16

## 券種
新規予想は単勝・馬連・ワイドの3券種だけです。三連複は新規買い目から外しました。旧履歴は消しません。

## 実績ベース購入フィルター
予想時EVだけでなく、蓄積した公式払戻実績を購入判定に使います。券種・中央/地方・芝ダート・距離帯・荒れ度ごとの成績を参照し、弱い条件では必要EVを自動的に厳しくします。

初期基準は単勝EV1.12、馬連1.28、ワイド1.22付近。過去実績が弱ければさらに上げます。

## 荒れ度予測
各レースを「荒」「中」「堅」で表示します。AI1位勝率、上位3頭の確率集中、1-2位差、勝率分布、頭数、単勝オッズ、先行馬数を使います。1.16以降は荒れ度別の公式払戻ROIも分析画面で確認できます。

## 購入方針
70%を無理に狙って点数を増やす方式はやめ、実績的に勝ちやすい条件を優先します。目標70%・120%はモニターとして残します。
