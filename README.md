# UmaScope Free AutoBet 1.4 — 詳細出馬表解析修正版

## 1.4で直した点
- NARの「印刷用出馬表 / 詳細出馬表」の本文を直接解析
- 取込ブックマークが取得した `narDetailTables` を解析側でも使用
- 地方競馬の取込JSONを軽量化し、iPhoneのクリップボード負荷を低減
- 全角数字・空白・タブが混ざる詳細出馬表にも対応
- 地方の近走日付（月日表記）を開催年から正しく補完
- 騎手・斤量を詳細出馬表から再取得
- 1.3の履歴・馬DB・バックテスト機能をそのまま継承
- 1.3バックアップJSONも復元可能

## 更新時に重要
この版では `bookmarklet.txt` も変更しています。
GitHub Pagesを1.4へ更新した後、UmaScopeの「設定」→「コードをコピー」で
Safariの「UmaScope取込」ブックマークのURLを必ず貼り替えてください。

## 地方競馬の使い方
1. 地方競馬情報サイトで対象レースの「出馬表」または「印刷用出馬表」を開く
2. Safariのブックマークから「UmaScope取込」を実行
3. 「UmaScope用データをコピーしました（xxKB）」が出る
4. UmaScope 1.4 →「クリップボードから解析」
5. 馬名・騎手・近走が反映されることを確認

## データについて
無料・iPhone完結の方針を維持し、公式サイトを常時巡回する方式にはしていません。
