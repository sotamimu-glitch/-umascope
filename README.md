# UmaScope Free AutoBet 1.10.1 — 結果反映修正版

## 修正内容
1.10で「結果を反映」を押しても更新されない不具合を修正しました。

原因は結果保存関数の定義が
`window.settlewindow.settle`
となっていたことです。1.10.1では正しく `window.settle` として登録します。

## 結果入力後に更新されるもの
- AI予想1〜3位 ↔ 実際の1〜3着
- AI1位が1着だったか
- AI上位3頭のうち実際の3着内に何頭入ったか
- AI提示全買い目の的中数・的中率
- 100円均等買い回収率
- 全レース累計の買い目的中率・レース的中率・回収率

「実際の投資額」「実際の払戻額」は任意です。
均等買い回収率は、保存時オッズから自動計算します。
