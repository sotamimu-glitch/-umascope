# UmaScope Free AutoBet 1.6 — JRA会場名・レース番号修正版

## 1.6で直した点
- JRAの通常出馬表と詳細側データを分離して解析
- 馬名・騎手・近走は詳細/表データを利用
- 会場名・何Rか・開催日は通常出馬表のヘッダーを優先
- ヘッダーで取れない場合はJRAのURLから補完
- JRA競馬場コード 01〜10 に対応
  - 01札幌 / 02函館 / 03福島 / 04新潟 / 05東京
  - 06中山 / 07中京 / 08京都 / 09阪神 / 10小倉
- 1.5までの近走解析・バックテスト機能はそのまま

## 更新方法
GitHub Pagesの以下を1.6のファイルで置き換えてください。
- index.html
- core.js
- sw.js
- manifest.webmanifest

bookmarklet.txt は1.5と同じ内容なので、今回は取込ブックマークの貼り替えは必須ではありません。

## 確認
JRAの普通の「出馬表」を開いて取込後、
「札幌 11R 第61回札幌2歳ステークス」のように
会場名とレース番号が表示されれば成功です。
