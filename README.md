# UmaScope Free AutoBet 1.19.2 — ROI期間集計修正

## 変更内容
予測ロジック・確率計算・買い目生成・購入判定は1.19.1から変更していません。

条件別ROIランキングの期間指定だけ修正しました。

### 修正前
「1.17以降」が `modelVersion` の文字列が 1.17 で始まる履歴だけを対象にしていたため、
1.19系の履歴が除外されていました。

### 修正後
- 1.17以降:
  1.17系 + 1.18相当の1.17モデル履歴 + 1.19系をすべて集計
- 1.19以降:
  1.19系を集計
- 全期間:
  バージョン制限なし

モデルバージョンを数値として比較する方式へ変更しました。

## 表示修正
1.19以降を選んだ場合も、見出しが誤って「1.17以降」と表示されていた問題を修正。
選択した期間をそのまま表示します。
