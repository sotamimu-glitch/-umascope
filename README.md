# UmaScope Free AutoBet 1.7 — 10特徴量モデル＋現実的買い目

## 新しい10特徴量
1. 着差
2. 人気（人気以上/以下に走ったか）
3. 頭数（多頭数を着順比率で補正）
4. 距離変化
5. 芝/ダート
6. 馬場状態
7. 騎手
8. 枠順
9. 斤量
10. 近3〜4走のパフォーマンス推移

配点:
- 着差 16%
- 人気 8%
- 頭数 8%
- 距離変化 12%
- 芝/ダート 10%
- 馬場状態 8%
- 騎手 10%
- 枠順 5%
- 斤量 7%
- 近走推移 16%

枠順と斤量は単独で過大評価しないよう低ウェイトです。

## 現実的な買い目
従来の「各券種最大3点」から変更しました。

- 1レース最大3〜5点
- モデル信頼度が低いほど最大点数を減らす
- 基本は上位馬を軸にする
- 単勝 最大1点
- ワイド 最大2点
- 馬連 最大2点
- 三連複 最大1点
- 原則2券種まで（高信頼時のみ3券種目を1点許可）
- 実オッズが取れている券だけを購入候補にする
- 基準未達なら「見送り」
- 予算を100円単位で自動配分

初期予算は1,000円。予想画面から変更できます。
