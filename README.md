# UmaScope Free AutoBet 1.3

中央競馬＋地方競馬対応、iPhone / GitHub Pages向けの無料PWAです。

## 1.3の追加機能

- 同じ馬の公式出馬表から取得した近走を端末内で重複除去して最大20走まで蓄積
- 直近だけでなく最大20走を時間減衰ウェイトで自動評価
- 保存レースに中央/地方、競馬場、距離、芝/ダート、馬場状態を記録
- 推奨買い目とは別に、バックテスト用候補をコンパクト保存
- 単勝・馬連・ワイド・三連複の券種別的中率
- 保存時オッズを使った「1点100円均等買い」理論回収率
- EV帯別（～0.99 / 1.00～1.09 / 1.10～1.19 / 1.20～1.29 / 1.30～）分析
- 中央/地方、競馬場、芝/ダート、距離帯、馬場状態で絞り込み
- ウォークフォワード検証：古い70%でEV基準を選び、新しい30%で別検証
- JSONバックアップ / 復元
- バックテスト明細CSV出力
- 1.2までの履歴は引き継ぎ可能（古い履歴にない条件項目は「不明」扱い）

## 普段の流れ

1. JRAまたは地方競馬情報サイトで公式出馬表を開く
2. 「UmaScope取込」ブックマークを実行
3. UmaScopeの「クリップボードから解析」
4. 予想・オッズを確認して保存
5. レース後に1着・2着・3着を入力
6. 「分析」で券種・EV帯・中央/地方・距離などの成績を確認

## 理論回収率

保存時点のオッズで、対象買い目をそれぞれ100円購入したと仮定します。

- ハズレ: 払戻0円
- 的中: `100円 × 保存時オッズ`
- 理論回収率: `理論払戻合計 ÷ 理論投資合計`

ワイドは取得時のオッズレンジの下限を使うため、理論払戻は保守的です。
オッズが取得できなかった買い目は的中率には使えますが、理論回収率からは除外します。

## ウォークフォワード検証

結果入力済みのレースを日付順に並べ、

- 古い約70%: EV 1.00 / 1.10 / 1.20 / 1.30を比較
- 新しい約30%: 古い70%で最良だった基準だけを検証

とします。最低6レース未満では「データ不足」を表示します。数十～数百レース程度ないと結果は大きくブレます。

## 馬ごとの過去走蓄積

公式出馬表から得た近走を馬名ごとに端末内保存します。同じ馬を別の日に再度取り込むと、重複を除いて履歴を足します。最大20走、最大400頭を保存します。

これはJRA/NARを一括巡回する仕組みではなく、ユーザーが開いたレースのデータだけを端末内で蓄積する方式です。

## GitHub更新

1.3へ更新する場合、GitHubの `umascope` にある以下を1.3のものへ置き換えます。

- `index.html`
- `core.js`
- `sw.js`
- `manifest.webmanifest`
- `README.md`（任意）

`bookmarklet.txt` は1.2から変更していません。既存の「UmaScope取込」ブックマークはそのまま使えます。

公開後、画面上部が **UmaScope Free AutoBet 1.3** になっていることを確認してください。

## データ保全

履歴・馬DBはSafariのlocalStorageに保存されます。Safariのサイトデータ削除などで消える可能性があるため、「設定 → JSONバックアップ」を定期的に保存してください。

## 注意

推定勝率・EV・バックテスト結果は将来の利益を保証しません。特に少数サンプルで最も回収率が高い条件を選ぶと過学習しやすいため、ウォークフォワードの後半検証を重視してください。
